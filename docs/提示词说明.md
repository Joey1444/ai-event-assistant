# 提示词说明（Agent 文档）

本文档只写**不变的约定**。每个 Agent 的具体角色、输入、输出字段、规则，一律以代码为准：`lib/agents/registry.ts`（清单 + 元数据）+ 各 `lib/agents/*.ts`（真实 prompt）。

## 通用提示词结构

每个 Agent 的 prompt 都遵循同一骨架：

```
# 角色   你是谁、唯一职责是什么
# 输入   你会收到什么材料
# 输出   严格 JSON + 每个字段的含义
# 规则   反幻觉 + 事实规则 + 格式规则
```

## 统一反幻觉原则（贯穿所有 Agent）

- 绝不编造事实。
- 无来源 / 无法确定的信息标 `UNKNOWN` 或 `[待确认]`。
- 推测只能标 `ASSUMPTION`，绝不写成事实。
- 事实账本里 `UNKNOWN/CONFLICT/ASSUMPTION` 的信息不当确定事实用。

> 反幻觉的完整铁律以 `rules/AI_DEVELOPMENT_RULES.md` 为唯一权威，本处不重复。

## 找某个 Agent 的详情

- 顺序与元数据：`lib/agents/registry.ts` 的 `AGENTS` 数组（也是流水线顺序）。
- 字段与规则：各 `lib/agents/*.ts` 里的 prompt。
